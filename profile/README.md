# RS Partition Recovery — preview before a restore pass

RS Partition Recovery holds a recovery desk for a partition scan on a volume you own: the file preview before restore, the hits, and a short note the next operator can read. Extra volumes wait for their own title.

## Session Card

| Slice | What you do in RS Partition Recovery | What remains |
|-------|------------------------|--------------|
| Arrival | Open RS Partition Recovery and name today's recovery desk | A titled partition scan |
| Focus | Keep only live hits on the RS Partition Recovery board | A short file preview |
| Check | Read RS Partition Recovery file preview before a restore | A confirmed recovery desk |
| Handoff | Mark finished hits inside RS Partition Recovery | A note for the next operator |
| Hold | Leave the scan title on the RS Partition Recovery list | A named partition scan |

## How RS Partition Recovery Sits

RS Partition Recovery does not replace a restore without preview, a partition scan of a volume you do not own, or a pass on media that is not yours. It sits beside them as a named recovery desk for one job: which partition scan is live, which file preview still matches your own volume, and what the next operator should read.

Each operator on a shared PC keeps an RS Partition Recovery style of their own. Extra volumes wait for their own title instead of crowding the live preview.

A first visit should be one short partition scan on a volume you own, then the same RS Partition Recovery recovery desk the next day. That is enough to see if the named file preview holds.

## Traffic Light

| Signal | On the RS Partition Recovery board | What you do |
|--------|----------------------|-------------|
| Green | Named partition scan, short live file preview | Continue the same own volume |
| Amber | Two volumes mixed on one preview | Split the hits before a large change |
| Red | No title, no note, a restore without preview | Stop and name the recovery desk first |
| Clear | Handoff written, live scans few | Close RS Partition Recovery and leave the recovery desk |
| Hold | Preview written, hits still open | Finish the named partition scan, then close |

## Open Order

1. Open the last RS Partition Recovery recovery desk, not a new empty partition scan.
2. Confirm the volume is yours, then read the file preview and the last handoff.
3. Finish one visible partition scan inside RS Partition Recovery on a volume you own.
4. Write what changed, then close with fewer unpreviewed restores than you found.
5. If the preview feels crowded, drop anything that belongs to a different RS Partition Recovery job.
6. Leave the recovery desk title on the board before you close.

## After a Week

A week in RS Partition Recovery is not a larger pile of unpreviewed restores. It is the same title, a shorter live file preview, and a note that still makes sense before the next partition scan.

Other programs stay where they are. RS Partition Recovery only keeps the path back: desk name, own volume, file preview, handoff.

Leave RS Partition Recovery with a quieter recovery desk than the one you opened. The next visit should start on that named partition scan, not on a volume you do not own.

## Sign-off

- [ ] The RS Partition Recovery workspace name is short enough to scan
- [ ] Only a volume you own sits on the partition scan
- [ ] A second operator can read the preview handoff
- [ ] The last RS Partition Recovery file preview still opens after a restart
- [ ] Finished hits are off the live RS Partition Recovery set
- [ ] The RS Partition Recovery summary still matches the own volume on the board

## Field Note

RS Partition Recovery is easier to trust when the recovery desk stays on a volume you own. Name the partition scan, keep the live file preview, finish one visible pass, and write what changed.

The same loop fits a review, a close-out, or a shared PC. Open the last RS Partition Recovery desk and continue. Do not restore a volume you are not authorized to recover.

A named file preview is enough. Do not pin every hit you keep onto the live recovery desk.
